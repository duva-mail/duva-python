# Duva for Python

The official [Duva](https://duva.ca) client library for Python. **Not released yet: this package name is reserved.**

Duva is a transactional email API hosted in Canada. In the meantime, the HTTP API is documented at
<https://duva.ca/en/docs> and described by an OpenAPI 3.1 specification at <https://duva.ca/openapi.json>.

# Duva pour Python

La bibliothèque cliente officielle de [Duva](https://duva.ca) pour Python. **Pas encore publiée : ce nom de paquet est réservé.**

Duva est une API de courriels transactionnels hébergée au Canada. En attendant, l'API HTTP est documentée sur
<https://duva.ca/docs> et décrite par une spécification OpenAPI 3.1 sur <https://duva.ca/openapi.json>.
